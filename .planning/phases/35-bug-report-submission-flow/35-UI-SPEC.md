| Property | Value |
|----------|-------|

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing, FAB icon padding |
| md | 16px | Default element spacing, dialog body padding |
| lg | 24px | Dialog section padding (--spacing-page: 1.5rem) |
| xl | 32px | Not used in this phase |
| 2xl | 48px | FAB size (width/height of circular button) |
| 3xl | 64px | Not used in this phase |

Exceptions:
- FAB bottom/right offset: 24px (bottom-6, right-6 in Tailwind)
- FAB mobile bottom offset: 80px (bottom-20 in Tailwind) to clear MobileNav bar
- FAB touch target: 48px diameter (meets 44px minimum WCAG touch target)

| Property | Value |

### 2. Bug Report Dialog

| Property | Value |
|----------|-------|
| Component | shadcn `Dialog` + `DialogContent` |
| Width | `sm:max-w-md` (448px max on desktop) |
| Title | "Report a Bug" in `DialogHeader > DialogTitle` |
| Layout | Single column: title, textarea, page URL hint, footer with actions |

### 3. Description Textarea

| Property | Value |
|----------|-------|
| Component | shadcn `Textarea` |
| Label | "What went wrong?" (text-sm font-semibold) |
| Placeholder | "Describe the issue you encountered..." |
| Rows | 4 (initial height) |
| Max length | 2000 characters |
| Min length | 10 characters (client-side validation per D-12) |
| Resize | `resize-none` (fixed height, prevents layout shift in dialog) |
| Character count | `{length}/2000` in text-xs text-muted-foreground, right-aligned below textarea |
| Validation error | text-xs text-destructive, shown below textarea when < 10 chars on blur or submit attempt |

### 4. Page URL Hint

| Property | Value |
|----------|-------|
| Position | Below textarea, above dialog footer |
| Content | `Page: {window.location.pathname}` |
| Style | `text-xs text-muted-foreground` with `MapPin` icon (12px) inline |
| Purpose | Builds user trust that context is auto-captured (D-04) |

### 5. Dialog Footer Actions

| Property | Value |
|----------|-------|
| Layout | `DialogFooter` -- right-aligned, `flex gap-2` |

| Submit loading | Icon swaps to `Loader2` with `animate-spin`, text changes to "Submitting...", button disabled |
| Submit disabled when | description.trim().length < 10 OR submitting OR cooldown active |

### 6. Success Toast

## Interaction States

### FAB States

| State | Visual |
|-------|--------|
| Default | 48px indigo circle, white Bug icon, shadow-lg |
| Hover | bg-primary/90 (slightly dimmed) |
| Focus | Ring-2 ring-ring ring-offset-2 |
| Active/pressed | scale-95 (brief press feedback) |
| Cooldown (30s post-submit) | opacity-50, cursor-not-allowed, tooltip shows "Report submitted recently" |
| Dialog open | FAB hidden (no need for two visible controls) |

### Dialog States

| State | Visual |
|-------|--------|
| Open (empty) | Textarea empty, Submit disabled (opacity-50), character count "0/2000" |
| Typing (< 10 chars) | Submit remains disabled, character count updates live |
| Typing (>= 10 chars) | Submit enabled (full opacity), character count updates live |
| Submitting | Submit shows Loader2 spinner + "Submitting...", all inputs disabled |
| Success | Dialog closes, success toast appears, FAB enters cooldown |
| Error | Dialog stays open, error toast appears, user can retry |

### Textarea Validation

| Trigger | Behavior |
|---------|----------|
| On mount | No validation shown |
| On blur (< 10 chars, non-empty) | Show validation error below textarea |
| On submit attempt (< 10 chars) | Show validation error, do not submit |
| On input (after error shown) | Clear error when length >= 10 |

## Responsive Behavior

| Breakpoint | FAB Position | Dialog Width |
|------------|-------------|--------------|
| < 768px (mobile) | `fixed bottom-20 right-6` (clears MobileNav) | Full width with 16px margin (`mx-4`) |
| >= 768px (desktop) | `fixed bottom-6 right-6` | `max-w-md` (448px), centered overlay |

The FAB uses `md:bottom-6 bottom-20` to adapt. Dialog width is handled by shadcn DialogContent defaults which are already responsive.

## Accessibility

| Requirement | Implementation |
|-------------|---------------|
| FAB keyboard access | Standard button element, focusable via Tab |
| FAB screen reader | `aria-label="Report a bug"` on the button |
| Tooltip | shadcn Tooltip provides aria-describedby automatically |
| Dialog focus trap | Radix Dialog provides focus trap by default |
| Dialog close on Escape | Radix Dialog handles this by default |
| Textarea label | Visible `<Label>` element associated via htmlFor |
| Error announcement | Validation error uses `aria-live="polite"` region |
| Toast announcement | sonner provides aria-live region by default |
| Reduced motion | Global `prefers-reduced-motion` rule in globals.css disables animations |
| Color contrast | Primary (indigo) on white foreground meets WCAG AA (4.5:1+) |
