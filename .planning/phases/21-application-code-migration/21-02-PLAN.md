1. Rewrite `lib/storage/index.ts` completely:
   - Import `S3Client`, `PutObjectCommand`, `GetObjectCommand`, `DeleteObjectCommand` from `@aws-sdk/client-s3`
   - Import `fromNodeProviderChain` from `@aws-sdk/credential-providers`
   - Change `StorageMode` type to `"local" | "s3"` (per user decision: rename "blob" to "s3")
   - Rename interfaces:
     - `StoredFile` fields: `blobUrl` -> `storageUrl`, `blobPathname` -> `storageKey`
     - `UploadResult` fields: `blobUrl` -> `storageUrl`, `blobPathname` -> `storageKey`
   - Create S3 client singleton: `new S3Client({ region: process.env.AWS_REGION || "us-east-1" })`
   - Read bucket name from `process.env.S3_BUCKET_NAME`
   - Add `async function hasAwsCredentials(): Promise<boolean>` that calls `fromNodeProviderChain()()` in try/catch
   - Add credential caching: module-level `let _hasCredentials: boolean | null = null` with async getter that caches the result
   - Update `getStorageMode()`:
     - If `UPLOAD_STORAGE` env var is explicitly set to "s3" or "local", use that
     - Otherwise, auto-detect: if AWS credentials available, use "s3"; else "local"
     - Return type `StorageMode` ("local" | "s3")
     - Note: since this now needs async credential check, make `getStorageMode()` async
   - Replace `isBlobMode()` with `isS3Mode()` returning `getStorageMode() === "s3"` (also async)
   - Update `uploadToStorage()`:
     - In "s3" mode: generate key as `uploads/${Date.now()}-${filename}`, use `PutObjectCommand` with Bucket/Key/Body/ContentType
     - Return `{ storageUrl: \`s3://${BUCKET}/${key}\`, storageKey: key }`
     - In "local" mode: return empty object (same as before)
   - Update `getFileBuffer()`:
     - Rename parameter from `blobUrl` to `storageKey`
     - In "s3" mode: use `GetObjectCommand` with Bucket/Key, convert Body stream to Buffer using `response.Body!.transformToByteArray()`
     - In "local" mode: return provided buffer (same as before)
   - Update `deleteFromStorage()`:
     - Rename parameter from `blobUrl` to `storageKey`
     - In "s3" mode: use `DeleteObjectCommand` with Bucket/Key
     - Keep try/catch with console.warn on failure
   - Update all function signatures to be async where needed
   - Remove all `@vercel/blob` imports

2. Update `prisma/schema.prisma`:
   - Rename `blobUrl` to `storageUrl` in the Upload model
   - Rename `blobPathname` to `storageKey` in the Upload model

   - Run `npx prisma migrate dev --name rename-blob-to-storage` to create the migration
     - This will generate a migration file with ALTER TABLE RENAME COLUMN statements
   - Run `npx prisma generate` to regenerate the client

IMPORTANT: After `getStorageMode()` becomes async, all callers need updating. The callers in THIS plan's files (storage/index.ts internal calls) are handled here. Callers in OTHER files (upload route, upload component) are handled in Task 2.
