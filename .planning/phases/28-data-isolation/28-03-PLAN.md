<objective>
Add ownership enforcement to all API routes and page components that access project data, completing the data isolation layer.

Purpose: API routes are polled by the client for progress updates and file uploads. Without ownership checks, a user could craft requests to access another user's data. Page components must also filter to user-scoped data.
Output: All API routes return 404 JSON for unauthorized access. All page components show only the current user's data.
</objective>

  <action>
    Read each API route file first, then apply ownership checks. In API route handlers, use `getCurrentUser()` and `isAdmin()` directly -- do NOT use `getAuthorizedProject()` because it calls `notFound()` which throws in route handlers.

    **Pattern for /api/projects/[id]/* routes (active-run, active-batch-story-run, active-subtask-run):**
    ```typescript
    import { getCurrentUser } from "@/lib/auth";
    import { isAdmin } from "@/lib/auth/authorization";

    export async function GET(request: NextRequest, { params }: { params: Promise<{ id: string }> }) {
      const user = await getCurrentUser();
      const { id } = await params;

      const project = await db.project.findUnique({ where: { id }, select: { userId: true } });
      if (!project || (project.userId !== user.email && !isAdmin(user.email))) {
        return NextResponse.json({ error: "Project not found" }, { status: 404 });
      }
      // ... rest of existing logic
    }
    ```

    **Pattern for /api/uploads route:**
    - GET handler: Extract projectId from query string (`request.nextUrl.searchParams.get("projectId")`). Verify the user owns that project before returning uploads.
    - POST handler: Extract projectId from the form data. Verify ownership before creating the upload.
    - Use the same pattern: fetch project, check userId match or admin, return 404 JSON if unauthorized.

    **Pattern for /api/runs/[id]/* routes (run detail, batch-story, subtask-progress):**
    - These routes receive a run ID, not a project ID. Must join through the run to its project.
    ```typescript
    const run = await db.run.findUnique({
      where: { id },
      include: { project: { select: { userId: true } } },
    });
    if (!run || (run.project.userId !== user.email && !isAdmin(user.email))) {
      return NextResponse.json({ error: "Run not found" }, { status: 404 });
    }
    ```

    **Special case -- /api/cron/recover-stale-runs:** Do NOT add ownership checks. This is a system cron route called without a user session. Leave it unchanged.

    **Special case -- /api/health, /api/auth/*:** No changes needed. These don't access project data.

    IMPORTANT: Do not change response shapes for successful requests. Only add the ownership gate at the top of each handler.
