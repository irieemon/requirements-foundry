  <files>lib/auth/types.ts, lib/auth/cognito.ts, lib/auth/__tests__/cognito.test.ts, package.json</files>
  <behavior>
    - buildAuthorizeUrl() returns URL starting with https://{COGNITO_DOMAIN}/oauth2/authorize
    - buildAuthorizeUrl() includes response_type=code, client_id, redirect_uri, scope=openid+profile+email, identity_provider=Okta
    - buildAuthorizeUrl("/projects/123") encodes return path in state parameter
    - buildAuthorizeUrl() without returnTo defaults state to "/"
    - buildLogoutUrl() returns URL starting with https://{COGNITO_DOMAIN}/logout
    - buildLogoutUrl() includes client_id and logout_uri pointing to app root
    - exchangeCodeForTokens() sends POST with grant_type=authorization_code, code, redirect_uri, client_id, client_secret
    - exchangeCodeForTokens() returns parsed JSON with id_token, access_token, refresh_token, expires_in
    - refreshTokens() sends POST with grant_type=refresh_token and refresh_token parameter
  </behavior>
  <action>
    1. Run `npm install aws-jwt-verify iron-session` to add dependencies.

    2. Create `lib/auth/types.ts` with:
       - `SessionData` interface: refreshToken (string), expiresAt (number, unix timestamp), user (UserInfo object)
       - `UserInfo` interface: sub (string), email (string), name (string), groups (string[])
       - Note: Do NOT store full idToken in session (cookie size pitfall from research). Store only claims + refresh token.

    3. Create `lib/auth/cognito.ts` with:
       - `buildAuthorizeUrl(returnTo?: string): string` -- constructs Cognito authorize URL with identity_provider=Okta parameter (per user decision: bypass Cognito Hosted UI). Uses env vars: COGNITO_DOMAIN, COGNITO_CLIENT_ID, COGNITO_REDIRECT_URI. State parameter encodes returnTo for deep link preservation.
       - `buildLogoutUrl(): string` -- constructs Cognito logout URL. Uses COGNITO_DOMAIN, COGNITO_CLIENT_ID. logout_uri is the app root URL (from COGNITO_REDIRECT_URI, strip the /api/auth/callback path, or use a NEXT_PUBLIC_APP_URL env var). Per user decision: Cognito logout only, no Okta SLO.
       - `exchangeCodeForTokens(code: string): Promise<{id_token: string, access_token: string, refresh_token: string, expires_in: number}>` -- POST to Cognito token endpoint with authorization_code grant. Include client_secret (COGNITO_CLIENT_SECRET env var).
       - `refreshTokens(refreshToken: string): Promise<{id_token: string, access_token: string, expires_in: number}>` -- POST to Cognito token endpoint with refresh_token grant for silent re-auth.

    4. Write tests in `lib/auth/__tests__/cognito.test.ts`:
       - Set env vars in beforeEach, clean in afterEach
       - Test all behaviors listed above
       - Mock global fetch for exchangeCodeForTokens and refreshTokens tests
       - RED phase: write all tests first, run vitest (expect failures), commit
       - GREEN phase: implement cognito.ts to pass all tests, commit
