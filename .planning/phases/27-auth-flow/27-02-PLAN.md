<task type="auto" tdd="true">
  <name>Task 1: proxy.ts route protection with JWT verification and token refresh</name>
  <files>proxy.ts, __tests__/proxy.test.ts</files>
  <behavior>
    - Public routes (/, /api/health, /api/cron/*, /_next/*, /favicon.ico, /api/auth/*) pass through without auth check
    - Request to /projects with no session cookie redirects to /?returnTo=/projects
    - Request to /projects/abc-123 with no session redirects to /?returnTo=/projects/abc-123
    - Request with valid non-expired session passes through
    - Request with session expiring within 5 minutes triggers refreshTokens() call, updates session, passes through
    - Request with failed token refresh (e.g., revoked refresh token) redirects to / for re-auth
    - Request with expired session and no refresh token redirects to /
  </behavior>
  <action>
    Create `proxy.ts` at project root (Next.js 16 pattern, replaces deprecated middleware.ts). This runs on Node.js runtime, NOT Edge.

    The proxy function:
    1. Check if request URL matches public routes -- if so, return NextResponse.next()
    2. Read session via iron-session (using getIronSession with request cookies, NOT the cookies() helper which is for server components)
    3. If no session or no session.user, redirect to `/?returnTo={pathname}`
    4. If session.expiresAt is within 5 minutes of current time (300 seconds), attempt transparent refresh:
       - Call refreshTokens(session.refreshToken)
       - On success: verify new ID token, update session.expiresAt and session.user claims, save session
       - On failure: clear session, redirect to / for re-auth (silent re-auth via Cognito/Okta SSO per user decision)
    5. If session is valid and not near-expiry, return NextResponse.next()

    IMPORTANT: proxy.ts reads cookies from the request object directly, not via `cookies()` from `next/headers`. Use `getIronSession` with the request/response pattern suitable for proxy context. Check iron-session docs for the correct pattern with NextRequest.

    Export config with matcher that excludes static files:
    ```
    matcher: ['/((?!_next/static|_next/image|favicon\\.ico).*)']
    ```
    Then additionally check pathname inside the function for /api/health, /api/cron/, /, and /api/auth/ routes.

    Write tests in `__tests__/proxy.test.ts`:
    - Mock iron-session and auth modules
    - Test each behavior listed above
    - Focus on the route matching logic and refresh threshold logic
    - RED then GREEN commits
  </action>
  <verify>
    <automated>npx vitest run __tests__/proxy.test.ts --reporter=verbose</automated>
  </verify>
  <done>proxy.ts intercepts all non-public routes, verifies sessions, refreshes near-expiry tokens, redirects unauthenticated users. All proxy tests pass.</done>
</task>
