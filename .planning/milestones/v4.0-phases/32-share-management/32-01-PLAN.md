    Five exported functions:

    1. `searchUsers(query: string, projectId: string, excludeUserIds: string[] = [])`:
       - If query.length < 2, return []
       - Look up project to get owner email: `db.project.findUnique({ where: { id: projectId }, select: { userId: true } })`
       - Look up owner's User record: `db.user.findUnique({ where: { email: project.userId }, select: { id: true } })`
       - Build excludeIds array: [...excludeUserIds, ownerUserId] (if owner found)
       - Query: `db.user.findMany({ where: { AND: [{ id: { notIn: excludeIds } }, { OR: [{ email: { contains: query, mode: "insensitive" } }, { name: { contains: query, mode: "insensitive" } }] }] }, select: { id: true, email: true, name: true }, take: 10 })`
       - Return the results array directly

    2. `shareProject(projectId: string, userId: string, role: "editor" | "viewer" = "editor")`:
       - Call `getAuthorizedProject(projectId)` to get caller's role
       - If role !== "owner" && role !== "admin", return `{ success: false, error: "Only owners can share projects" }`
       - Try `db.projectShare.create({ data: { projectId, userId, role } })`
       - Catch Prisma P2002 (unique constraint): return `{ success: false, error: "User already has access to this project" }`
       - Call `revalidatePath(\`/projects/\${projectId}\`)`
       - Return `{ success: true }`

    3. `updateShareRole(shareId: string, role: "editor" | "viewer")`:
       - Find share: `db.projectShare.findUnique({ where: { id: shareId } })`
       - If not found, return `{ success: false, error: "Share not found" }`
       - Call `getAuthorizedProject(share.projectId)` for caller's role
       - If caller role !== "owner" && !== "admin", return `{ success: false, error: "Only owners can modify shares" }`
       - `db.projectShare.update({ where: { id: shareId }, data: { role } })`
       - `revalidatePath(\`/projects/\${share.projectId}\`)`
       - Return `{ success: true }`

    4. `removeShare(shareId: string)`:
       - Find share: `db.projectShare.findUnique({ where: { id: shareId } })`
       - If not found, return `{ success: false, error: "Share not found" }`
       - Call `getAuthorizedProject(share.projectId)` for caller's role
       - If caller role !== "owner" && !== "admin", return `{ success: false, error: "Only owners can remove shares" }`
       - `db.projectShare.delete({ where: { id: shareId } })`
       - `revalidatePath(\`/projects/\${share.projectId}\`)`
       - Return `{ success: true }`

    5. `getProjectShares(projectId: string)`:
       - Call `getAuthorizedProject(projectId)` for caller's role
       - If caller role !== "owner" && !== "admin", return `{ success: false, error: "Only owners can view shares", shares: [] }`
       - Query: `db.projectShare.findMany({ where: { projectId }, include: { user: { select: { id: true, email: true, name: true } } }, orderBy: { createdAt: "asc" } })`
       - Return `{ success: true, shares }`

    Handle the Prisma P2002 error in shareProject:

    import { Prisma } from "@prisma/client";

    if (error instanceof Prisma.PrismaClientKnownRequestError && error.code === "P2002") {

    }
